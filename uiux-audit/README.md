# SILIQ 官網 UI／UX 檢查

後續已依此建議完成本機改版：[修改紀錄與新版預覽](IMPLEMENTATION.md)。以下保留改版前的檢查內容。

檢查日期：2026-09-09。以工作區程式與本機 Chromium 畫面為準，桌機 1440 × 1000、手機 390 × 844。正式網址本次未能透過網頁工具取得，因此未確認線上部署是否與本機相同。此次新增檢查紀錄與截圖，未修改網站程式。

## 視覺方向

建議保留現有鼠尾草綠與深綠識別，走「精品品牌顧問 × 創意影像工作室」：米白底、深綠大標、真實案例照片、少量細線與柔和陰影。用作品與編排建立個性，減少每個區塊都採置中標題、等寬卡片的重複感。

## 具體版型建議

首頁順序：主視覺與價值主張 → 精選案例與成果 → 主力服務 → 合作方式 → 團隊與客戶評價 → 常見問題 → 諮詢入口。

主標文案可測試「讓你的品牌，被看見，也被選擇。」副標接續說明實際服務：「從短影音、社群經營到品牌策略，SILIQ 陪你把內容做成生意。」這些是設計提案，應依實際主力客群與服務確認。

案例內容建議採「客戶／產業 → 原本需求 → SILIQ 做了什麼 → 可核實成果」。目前已有觀看數素材，可以強化版面，但須標明統計期間與數據定義，不把觀看次數當作營收成果。

字級建議：桌機主標 56–72px、手機主標 32–40px，依實際斷行調整；正文 16–18px、行高約 1.7–1.9。縮小手機 Logo，讓頁首比例更輕盈。主要按鈕採深綠，次要按鈕使用描邊或文字樣式；減少裝飾性漂浮動畫。

## 互動補強

- 手機選單補上展開狀態、Escape 關閉與焦點管理；燈箱加入對話框語意與關閉後焦點返回。
- 客戶評價目前每 5 秒輪播；增加暫停操作，或改成靜態評價卡，讓使用者能讀完。
- 捲動動畫目前預設隱藏內容；加入減少動態效果偏好與程式失效時的可讀備援。
- 知識庫讀取失敗目前顯示「文章載入中...」，應改為明確失敗提示與重試入口。
