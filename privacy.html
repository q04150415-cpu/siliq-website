隱私權政策

最後更新：2026 年 9 月 1 日

希利克鳥有限公司（品牌名「SILIQ 行銷」，以下簡稱「本公司」）重視您的隱私。本政策說明本公司自有的內容發布工具「siliq video uploader」如何存取、使用與保護資料，包括透過 Google、Meta（Facebook／Instagram）等平台 API 取得的授權資料。

一、本工具的用途

「siliq video uploader」是本公司內部使用的自動化工具，用於將本公司自有帳號的影片與圖文內容，發布到本公司自有的社群平台頻道（YouTube、Facebook 粉絲專頁、Instagram）。本工具僅供本公司營運使用，不對外提供服務、不代表第三方存取其帳號。

二、我們存取的資料範圍

  • YouTube（Google 帳戶）：僅取得「上傳與管理本頻道影片」的權限（youtube.upload），用於將影片上傳到本公司自有的 YouTube 頻道。
  • Facebook／Instagram（Meta）：取得發布貼文與 Reels 短影片到本公司自有粉絲專頁與帳號的權限。

本工具不會讀取您的個人私訊、聯絡人、觀看紀錄，或上述用途以外的任何資料。

三、資料的使用與儲存

授權憑證（access token／refresh token）僅儲存在本公司自有、受控管的作業設備上，用於執行影片與內容的自動發布，不會傳輸給任何第三方，也不會用於發布以外的目的。

四、資料分享

本公司不會將透過平台 API 取得的資料出售、出租或分享給任何第三方，法律要求或平台政策要求者除外。

五、Google 使用者資料的有限使用聲明

本工具對 Google API 所取得資訊的使用與傳輸，均遵循《Google API Services User Data Policy》，包含其中的「有限使用（Limited Use）」要求。本工具僅將 Google 使用者資料用於上述影片發布功能，不用於廣告，也不將資料提供給資料仲介或用於任何無關用途。

六、資料安全

本公司採取合理的技術與管理措施保護所儲存的授權憑證，避免未經授權的存取。您可隨時於 Google 帳戶或 Meta 帳戶的安全設定中撤銷本工具的授權。

七、政策變更

本政策如有更新，將於本頁面公布，並更新上方的「最後更新」日期。
